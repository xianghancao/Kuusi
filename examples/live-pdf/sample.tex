\section{Open in JupyterLab}

\begin{enumerate}
  \item In the file browser, open the \texttt{examples/live-pdf} folder.
  \item Right-click \texttt{sample.pdf} and choose \textbf{Open with Kuusi Live PDF}.
  \item Keep the viewer open while you edit this \texttt{.tex} file elsewhere.
\end{enumerate}

\section{Live reload}

Compile locally, for example:

\begin{verbatim}
cd examples/live-pdf
pdflatex sample.tex
\end{verbatim}

When \texttt{sample.pdf} changes on disk, Kuusi Live PDF reloads it automatically
and tries to keep your scroll position.

\section{Edit this section}

\section{Try the toolbar}

Use the viewer controls while this PDF stays open:

\begin{itemize}
  \item \textbf{Refresh} reloads from disk without losing scroll when possible.
  \item \textbf{Page nav} and the page input jump between pages in this two-page sample.
  \item \textbf{Width / Page / 100\%} adjust zoom; \textbf{Auto reload} watches file changes.
\end{itemize}
